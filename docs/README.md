## Getting Started

To run this project in a web browser:

```bash
flutter pub get
flutter run -d chrome
```

For production web build:

```bash
flutter build web
```

The built web files will be available in the `build/web` directory.

## Project Overview
spacrm_super_admin is a super admin dashboard application for managing salon businesses, built with Flutter and Firebase. It provides authentication, analytics, salon management, audit trails, and settings management.
